# AWS Cloud & AI Engineering Portfolio

A dedicated technical portfolio showcasing practical, hands-on implementations across AWS Cloud infrastructure and modern AI engineering. Projects focus on bridging foundational cloud patterns—such as IaC, event-driven serverless architectures, and security compliance—with production-ready Generative AI agent workflows.

---

## 🎯 Purpose & Focus Areas

* **Cloud Infrastructure & IaC:** Deploying reproducible, production-grade architectures with Terraform and AWS CloudFormation.
* **Agentic & Generative AI:** Building autonomous agent workflows, runtime containers, and tool integrations using Amazon Bedrock and Anthropic Claude.
* **Security & Governance:** Implementing least-privilege IAM policies, Service Control Policies (SCPs), and compliance-aligned baseline controls.
* **Resilience & Automation:** Automating disaster recovery failovers, telemetry/tracing, and event-driven pipelines using Python (Boto3).
